# 人形机器人模块测试平台

面向已集成驱动器的机器人总成，提供手臂、胸腔和腿部测试台架的机械资料，以及配套控制柜的供电、通信与测量架构。

## 系统组成

Linux 上位机通过以太网连接 PLC，管理电源设定、KM0 和四路供电；通过独立 USB-CAN / CAN FD 接口连接机器人。机器人总成固定在台架上，支路电压和电流由控制柜采集。

![平台硬件架构](mechanical/手臂胸腔/共用资料/architecture/platform-overview.png)

四路共用一台直流源，电压与总限流统一设定，支路可独立通断。机器人运动控制采用对应厂家的协议。

## 开始搭建

1. 选择台架，核对机器人型号、安装接口与运动范围。
2. 根据机械 BOM、加工图和系统采购表确定组件。
3. 按搭建说明设计供电、线束、通信、测量及防护。
4. 完成结构、电气和安全检查后，从单工位开始集成。

本目录提供硬件设计与集成资料。配套上位机及数据服务见 [软件入口](../software/README.md)；控制柜 PLC 接口和机器人运动协议需按实际设备适配与验证。承载、保护、回馈与安全停止应按具体总成和工况设计。
