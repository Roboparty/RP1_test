# 控制柜与电气系统

采用 LFD835 V1.9 四通道架构：一台可调直流源提供公共电压与总限流，KM0 管理直流源交流输入，四个支路独立通断，并分别采集电压和电流。

```text
交流输入
├── 保护器件 → KM0 → 可调直流源 → 四个受保护动力支路 → 机器人总成
└── 24 V 控制电源 → PLC、继电器、传感器与通信接口
```

Linux 上位机通过以太网连接 PLC 管理供电，通过 USB-CAN / CAN FD 独立连接机器人。机器人总成已集成驱动器，基础配置不另配关节驱动器。

采购表中的参考型号用于方案选型，实际规格需匹配供电条件、机器人负载和工况。施工应配套电气原理图、I/O 表、端子表和逐芯线束图；控制软件与机器人协议按具体接口集成。

普通 PLC、SSR、KM0 通断和上位机心跳不代替安全控制。保护协调、回馈、预充、散热、机械支撑和安全停止按平台风险与容量要求设计。
