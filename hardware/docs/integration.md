# 台架机械与电气的对接

## 一个工位的关系

机器人总成固定在台架上；柜端动力支路给总成供电；Linux PC 通过独立 CAN 网络控制该总成；电压/电流采样在柜支路端进行。台架本身不增加独立伺服驱动器，除非另外增加加载电机。

```text
Linux PC ── Ethernet ── PLC / 电气柜 ── 受保护动力支路 ── 机器人总成
   └──── USB-CAN / CAN FD ──────────────────────────────┘
                                                 │固定/约束
                                           台架 + 夹具 + 支撑
                                                 │
                          接地、线束固定、防护、安全停机与回馈处理
```

## 机械文件与电气采购的分工

| 机械部分 | 电气/系统需要配合的内容 |
|---|---|
| 台架框架、底板、调平/锁止结构 | 核对质量、反力矩、稳定性、锚固、移动状态和运动范围 |
| 腿部/手臂/胸部或腰部专用夹具 | 型号及安装孔一致；支撑不得依赖通电力矩或普通保持抱闸 |
| 接线盒安装板、板卡支架 | 电气元件安装空间、散热、防护、线束弯曲和维护空间 |
| 动力与通信线束 | 连接器逐针表、线径/压降、拖链、应力释放、屏蔽与参考地 |
| 金属台架和外壳 | 按设备类别设计保护连接和等电位方案，不把动力负极当 PE |
| 机械限位、防护区域 | 与安全控制方案共同评估；限位不自动替代防夹挤/坠落措施 |
| 腿部负载平台的运动/加载部件 | 不依据外形推断测试功能；核对真实运动副、加载路径和能量处理 |

## 集成顺序

1. 在机械索引中选择对应总装和夹具，确认与实际机器人型号匹配。
2. 冻结安装孔、方向、总质量、最大力矩、重心及运动包络，完成机械审查。
3. 取得厂家接口图，确定动力、CAN、辅助电源、安全及 PE 是否需要独立连接器。
4. 完成电气和线束图、保护/预充/回馈、安全停机与防重启方案。
5. 按 [搭建说明书](hardware-build-manual.md) 第 10 节完成投用条件检查，再接入总成。

结构模型用于工装设计与接口适配。允许载荷应按总质量、重心、最大力矩、运动包络和反力路径确定，并结合支撑、防坠、限位及防护形成完整方案。
