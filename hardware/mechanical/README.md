# 机械台架

三个台架按“腿部”和“手臂胸腔”两类组织。

```text
mechanical/
├── 腿部/
│   └── 腿部负载测试平台/   # CAD、机械 BOM
└── 手臂胸腔/
    ├── 手臂测试平台/       # 手臂工装图纸
    ├── 胸腔测试平台/       # 胸腔结构图纸
    └── 共用资料/           # 共享总装、加工图、BOM、架构图
```

| 台架 | 资料入口 | 用途 |
|---|---|---|
| 手臂测试平台 | [手臂工装](手臂胸腔/手臂测试平台/README.md) | 手臂总成固定与接口集成 |
| 胸腔测试平台 | [胸腔结构](手臂胸腔/胸腔测试平台/README.md) | 胸腔总成固定与接口集成 |
| 腿部负载测试平台 | [腿部平台](腿部/腿部负载测试平台/README.md) | 腿部固定与加载机构集成 |

手臂与胸腔使用[共用总装和配套资料](手臂胸腔/共用资料/README.md)。打开装配时应保持 CAD 文件及依赖资源的相对位置。

台架适配需核对安装孔、总质量、重心、反力矩和运动包络；允许载荷由结构计算与适用工况确定。
