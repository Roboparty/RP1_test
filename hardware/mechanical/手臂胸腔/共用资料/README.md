# 手臂与胸腔共用资料

| 目录 | 内容 |
|---|---|
| CAD 附件中的 cad/solidworks | 共享总装、零件、工程图及材质资源 |
| manufacturing | CNC、型材与钣金加工资料 |
| bom | 机械采购工作簿及分类采购表 |
| architecture | 全平台、肢体连接与单支路架构图 |

资料入口：[CAD 下载](../../README.md#下载-cad)、[机械采购表](bom/mechanical-procurement.csv)、[架构图](architecture/README.md)。解压后打开 `cad/solidworks/手部腿部胸部支架总装.SLDASM`。

CAD 文件与依赖资源需保持相对位置。采购以零件号、版本、对应工装与加工图为依据，避免重复统计总装和分类表中的相同零件。不同机器人型号的夹具不直接互换。
