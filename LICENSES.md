This repository contains software, test-platform designs, documentation and sample data. Licenses apply by material type; the root license does not relicense every file.

| Material owned by the project contributors | License |
| --- | --- |
| Source code, executable scripts, automated tests and software configuration in `software/`, `data-analysis/` and repository tooling | [Apache-2.0](LICENSE) |
| Test-platform mechanical and electrical designs, manufacturing drawings and associated original BOM data in `hardware/` | [CERN-OHL-W-2.0](hardware/LICENSE), within the scope in [hardware/SOURCE_LICENSE.md](hardware/SOURCE_LICENSE.md) |
| README files, guides, test methods in `test-cases/`, and explanatory diagrams | [CC-BY-SA-4.0](LICENSES/CC-BY-SA-4.0.txt) |
| Original hardware documentation, diagrams, templates and scripts covered by the existing MIT grant | [MIT](LICENSES/MIT.txt) remains available; see the [preserved notice](LICENSES/MIT-HARDWARE-NOTICE.txt) |
| Project-generated synthetic CSV/JSON sample data in `data-analysis/examples/`, explicitly identified as synthetic in its README or metadata | [CC0-1.0](LICENSES/CC0-1.0.txt) |

For the original hardware documentation and explanatory diagrams covered by MIT, CC-BY-SA-4.0 is an additional choice (`MIT OR CC-BY-SA-4.0`). Original scripts covered by that grant may instead be used under `MIT OR Apache-2.0`. The existing MIT permissions and attribution are retained.

Real measurements, customer or production records, and datasets without an explicit data license are not included in the CC0 grant. A script's license does not determine the license of its input or output data.

Supplier CAD, robot reference models, textures, logos, manufacturer documents, external SDKs and other third-party material retain their own rights. File-specific notices and third-party terms take precedence for those materials. See [THIRD_PARTY.md](THIRD_PARTY.md); the project does not claim to have verified ownership of every referenced CAD part or embedded asset.

Keep the applicable license texts and attribution when redistributing material. Use of RoboParty names and logos is not granted as a trademark license by this document.
