# PLC 协议与对接

当前控制协议为 Host Protocol V1.2 / HR1=`0x0102`，配套目标 PLC 软件 V1.5。接入前记录 PLC 返回的 HR1，再核对下载工程身份、源码和编译记录，确认协议与软件版本匹配。

| HR1 | 当前 HMI 范围 | 字段定义 |
|---|---|---|
| `0x0100` | 仅监控，无最终复位回执 | [V1.0](HOST_MODBUS_TCP_PROTOCOL_V1.0.md) |
| `0x0101` | 仅监控，解码复位与故障来源 | [V1.1](HOST_MODBUS_TCP_PROTOCOL_V1.1.md) |
| `0x0102` | 控制与监控，真实反馈新鲜性门控 | [V1.2](HOST_MODBUS_TCP_PROTOCOL_V1.2.md) |
| 其他 | 拒绝 | 需正式协议定义 |

Modbus 使用 PDU 零起始地址，V1.2 整帧读取 HR0～31 共 32 Word；命令 HR32～37 先写载荷后提交 CommandSeq。实际地址、单位和位定义以对应协议为准。控制连接第一次写入前检查版本。

## 状态与输出准入

PS1 反馈有效期由 `plc/freshness.py` 根据 HR29 的真实状态推进、HR30 供电周期、HR31 年龄和本地单调时钟共同判断。重复读数保留原有效期，已知重启或断线后重新确认反馈。

PS1/通道 ON 在最终写入前检查实际 V1.2、连接与状态新鲜性、PLC/Host/MainReady、有效真实反馈、设定 Applied/无 Rejected、模拟量范围以及锁态/故障。心跳和脉冲携带的保留 ON 同样检查；同帧成功回执与故障同时出现时先处理故障。

HR28 bit4/5 是人工重启锁/恢复耗尽。锁态拒绝普通 MainEnable、PS1 和通道 ON；人工锁按 PLC 现场流程解除，当前协议没有远程解锁命令。全 OFF 的 PLC 控制故障复位须等待匹配的最终 ResetAckSeq/ResetResult，之后分别核对 PS1 故障状态和人工锁状态。

排查故障时，保留故障前后带时间戳的状态、HR1/HR2/HR5/HR7/HR28～31 和命令回执，用完整时间线定位失败步骤。HR7 表示当前 ManagerState，HR5 状态码按实际下载源码解释。

## 主机默认时间参数

来源为 `factory_hmi/config/plc_cabinet.yaml`、`plc/config.py` 和 `plc/state_machine.py`，工位须核对实际配置。

| 项目 | 默认值 |
|---|---:|
| 心跳 / 轮询 | 500 / 200 ms |
| TCP 快照过期 | 1000 ms |
| 命令 / KM0 / PS1 阶段 | 各 5000 ms |
| Modbus 响应 / 重试 | 2000 ms / 1 次重试 |
| TCP 重连间隔 | 至少 2000 ms |
| PS1 真实反馈无推进失效 | 5000 ms |

MainReady 后通信阶段为 `5000 + ps1_timeout_ms + 2*poll_ms`，默认 10400 ms。冷启动总预算为 `5000 + km0_timeout_ms + 3*ps1_timeout_ms + 9*command_timeout_ms + 2*poll_ms`，默认 70400 ms。各局部阶段同时使用自己的期限，先到期即触发超时；建立后的轮询和重试沿用原截止时间。

这些数值是主机状态机的逻辑预算，实际判定时刻还受同步 TCP 调用、排队、扫描和主机调度影响。PLC→PS1 串口的重试由配套 PLC 工程管理。通信恢复后，输出需重新获得启动授权。

## 多窗口与停机

将所有控制窗口连接到同一网关，使其共享 PLC 客户端、映像、状态机和协调锁。独立网关之间没有写入协调机制。普通请求携带窗口/请求 ID、网关实例和控制版本；过期、冲突或已有 pending 时拒绝，操作员刷新状态后重新操作。同请求同内容重放既有结果，不同内容拒绝。

点击“全部停止”后，系统优先取消原操作并保持输出请求关闭，操作员等待并核对实际 OFF 反馈。网关按状态版本更新画面，忽略晚到的旧状态。紧急情况使用物理急停，软件停机请求仍需经过通信和调度。

## 投用条件

联调前，核对配套 PLC 工程的串口启动/恢复路径、各类超时和重试、端口重装上限、人工锁置清、通信故障恢复及反馈有效期，并与上表的局部和总预算对照。

现场逐项检查完整启动过程：

1. 确认真实 OFF 反馈。
2. 核对测量值、设定回读及应用确认。
3. 确认通信就绪后，再核对实际 ON 反馈和通道许可。
4. 验证故障、失联及恢复时的输出和锁态。

验收使用发布配置的期限和故障门槛，记录实际 PLC 工程/源码哈希、TIA 导入编译结果、下载身份、实际配置、命令回执及统一时钟的状态时间线。离线检查、安装验证和现场联调分别记录结果；预算或反馈不匹配时先修正配套工程，再重新联调。
