# PLC 协议与对接

当前控制协议为 Host Protocol V1.2 / HR1=`0x0102`，配套目标 PLC 软件 V1.5。软件版本与协议版本不同，实际使用以 PLC 返回的 HR1、下载工程身份、源码和编译记录共同核对。

| HR1 | 当前 HMI 范围 | 字段定义 |
|---|---|---|
| `0x0100` | 仅监控，无最终复位回执 | [V1.0](HOST_MODBUS_TCP_PROTOCOL_V1.0.md) |
| `0x0101` | 仅监控，解码复位与故障来源 | [V1.1](HOST_MODBUS_TCP_PROTOCOL_V1.1.md) |
| `0x0102` | 控制与监控，真实反馈新鲜性门控 | [V1.2](HOST_MODBUS_TCP_PROTOCOL_V1.2.md) |
| 其他 | 拒绝 | 需正式协议定义 |

Modbus 使用 PDU 零起始地址，V1.2 整帧读取 HR0～31 共 32 Word；命令 HR32～37 先写载荷后提交 CommandSeq。实际地址、单位和位定义以对应协议为准。控制连接第一次写入前检查版本。

## 状态与输出准入

TCP 读取成功不等于 PS1 有新反馈。`plc/freshness.py` 使用 HR29 的真实状态推进、HR30 供电周期、HR31 年龄和本地单调时钟；重复读数不刷新有效期，已知重启/断线撤销确认。

PS1/通道 ON 在最终写入前检查实际 V1.2、连接与状态新鲜性、PLC/Host/MainReady、有效真实反馈、设定 Applied/无 Rejected、模拟量范围以及锁态/故障。心跳和脉冲携带的保留 ON 同样检查；同帧成功回执与故障同时出现时先处理故障。

HR28 bit4/5 是人工重启锁/恢复耗尽。锁态拒绝普通 MainEnable、PS1 和通道 ON，不能发明解锁指令。全 OFF 的 PLC 控制故障复位须等待匹配的最终 ResetAckSeq/ResetResult；成功不代表 PS1 故障清除或人工锁解除。

HR7 是当前 ManagerState，不能用故障后一帧定位原始失败步骤；HR5 状态码也须结合实际下载源码解释。保留故障前后带时间戳的状态、HR1/HR2/HR5/HR7/HR28～31 和命令回执，不为补文档而通电复现。

## 主机默认时间参数

来源为 `factory_hmi/config/plc_cabinet.yaml`、`plc/config.py` 和 `plc/state_machine.py`，工位须核对实际配置。

| 项目 | 默认值 |
|---|---:|
| 心跳 / 轮询 | 500 / 200 ms |
| TCP 快照过期 | 1000 ms |
| 命令 / KM0 / PS1 阶段 | 各 5000 ms |
| Modbus 响应 / 重试 | 2000 ms / 1 次重试 |
| TCP 重连间隔 | 至少 2000 ms |
| PS1 真实反馈无推进失效 | 5000 ms |

MainReady 后通信阶段为 `5000 + ps1_timeout_ms + 2*poll_ms`，默认 10400 ms。冷启动总预算为 `5000 + km0_timeout_ms + 3*ps1_timeout_ms + 9*command_timeout_ms + 2*poll_ms`，默认 70400 ms；建立后轮询/重试不续期，局部阶段可更早超时。总预算不能替代局部期限。

同步 TCP 调用、排队、扫描与主机调度影响实际判定时刻，上述为逻辑预算，不是实机端到端硬上限。TCP 重试不等于 PLC→PS1 串口重试；持续重连也不自动恢复输出。

## 多窗口与停机

所有窗口必须连同一网关，共享 PLC 客户端、映像、状态机和协调锁。普通请求携带窗口/请求 ID、网关实例和控制版本；过期、冲突或已有 pending 时拒绝，不自动排队补发。同请求同内容重放既有结果，不同内容拒绝。

“全部停止”优先取消原操作并保持输出请求关闭，仍须等待实际 OFF 反馈。软件请求需经通信与调度，不能替代物理急停。晚到旧状态不得覆盖新画面；多网关对同一 PLC 的并发控制不在此机制范围内。

## 投用条件

配套工程须明确串口启动/恢复路径、每类超时和重试、端口重装上限、人工锁置清、通信故障恢复及反馈有效期，证明能覆盖 HMI 局部和总预算。完整启动还包括真实 OFF、测量/设定回读、应用确认、实际 ON 和通道许可，不能只证明 CommReady。

保留实际 PLC 工程/源码哈希、TIA 导入编译结果、下载身份和统一时钟的状态时间线；核对协议、实际配置、回执及失效保护。没有匹配证据时不把离线模型或 HMI 安装成功写成联合验收通过，也不通过放宽期限/故障门槛解决契约缺口。
