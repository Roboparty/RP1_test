# 2.0.0 软件发布验证

本文保留2.0.0发布时的验收口径。2026-10-15 中央归档与详细曲线源码的验收见 [CSV-ARCHIVE-IMPLEMENTATION.md](CSV-ARCHIVE-IMPLEMENTATION.md)，未部署生产或进行实物联调。2026-10-12工作区新增测试数据摘要审批，状态与验证以 [TEST-DATA-APPROVAL.md](TEST-DATA-APPROVAL.md) 为准；尚未应用到生产服务或已安装HMI。

本版从桌面项目源码构建 Ubuntu 24.04 amd64 deb。发布前已通过：

- 前端 lint、类型检查、47 项测试及生产构建；
- 后端 64 项非集成回归；
- 上位机 184 项回归及 119 项子检查，默认 PLC 配置隔离为 mock；
- PS1 输入 8 项、CAN 策略 8 项及 control/monitor 离线联锁检查；
- 原生 SDK 的 ABI、API、源文件摘要及依赖加载检查；
- 复用生产绑定的原生双 fake motor 并发检查：一台标零等待 1 秒期间，另一台持续发送模拟命令并读反馈，未创建 CAN socket。

软件测试不操作现场设备。安装包使用用户 GUI/网关入口，不安装自动启动服务；CAN 配置仍需要管理员认证。
以下保留旧版验收记录，旧系统服务和安装路径不作为本版操作说明。

## 1.0.1 历史验收范围

本版本发布为预发布工程版本，不能替代现场硬件与完整商业流程验收。

已完成自动化：前端 41 项测试及 lint/类型检查/生产构建；HMI 181 项与 116 个 subtest；在线监控后端 10 项测试（包含真实 PostgreSQL、Cookie、CSRF、权限和状态切换）。先前完整后端非集成套件通过，发布时再次验证交付副本。

已完成隔离联调：真实 HTTP HMI 登录、独立心跳、退出离线；浏览器运行→暂停→仅供电→退出离线；375px/桌面布局与深色主题。测试只使用独立 QA 数据库和 mock PLC。

Ubuntu 24.04 容器中验证 deb 安装、非 root 网关、Qt xcb 桌面启动，以及包内网关登录/心跳。已在原工位完成 0.1.0+plc4→1.0.1+ubuntu24.04 升级、配置保留和网关健康检查。未启动真实硬件测试，真实 PLC 原有通信故障不作为软件验收通过项。

发布前已在全新隔离目录实际完成 Compose 部署、24 次数据库迁移、HTTPS/数据库/worker 验证、首次登录改密与 HMI 状态联调、备份及新项目恢复演练。恢复后的改密账号、管理员权限、API 授权和工位记录与备份源一致。交付副本后端 64 项非集成测试通过。GitHub Actions 复现源码检查和 Ubuntu 24.04 HMI 构建；每次提交的具体结果以 Actions 日志为准。

## 未完成和边界

- 测试数据待审批区、审批人/理由、批准后原子发布正式数据、驳回重提和绕过旧 ingestion 的防护尚未实施。
- 在线监控独立于正式数据，不能把在线、上传成功或旧按钮文案理解为审批通过。
- 原始采集 CSV 仅在工位本地保存。仓库的静态测试目录 CSV 不是测量记录。
- 真实 PLC 映射、电机固件、CAN 适配器、急停、防护、时钟同步、长时间稳定性与现场故障恢复须另行验收。
- 对大量工位的容量压测、跨机容灾与完整商业 SLA 尚未验收。
