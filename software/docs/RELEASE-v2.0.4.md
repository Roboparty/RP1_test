# RP1 v2.0.4

包含 Reliability Platform 前端、后端、数据库与 RP1 上位机完整源码，以及由本标签对应的桌面 HMI 源码构建的 Ubuntu 24.04 amd64 安装包。

## 更新

- 支持 Host Protocol V1.1（0x0101）：故障复位等待 PLC 接收和最终结果回执，明确区分成功、条件不安全、仍锁存与超时；不再因首帧旧故障过早判失败。
- PLC 控制锁存、PS1 通信、PS1 设备故障独立显示，并与电机故障共同汇总到顶部。V1.0 可继续读数与原有控制，但禁用无最终回执的故障复位。
- VS1～VS4 保持 0～50 V 实测范围，V1.0/V1.1 均为 1 mV/计数；50000 对应 50.000 V。
- 两个窗口通过同一网关共享 PLC 指令与状态；过期和冲突指令明确拒绝，重复请求不重复写入，晚到状态不覆盖新画面。
- 回默认位统一为半增益 1 秒，再正常增益保持 2 秒；失能/断开取消回位并使此前排队的运动指令失效。
- 电压与电流趋势按实际数据自动缩放，可按通道筛选，改善约 2 A 小幅波动的可读性。
- 修复勾选“记录”后因缺少平台 bench_id 而启动失败：仅本地保存不要求平台工位身份，自动生成唯一记录号，生成本地报告与历史；平台记录使用完整档案身份并独立校验。
- 本地记录不会进入上传队列；原始采集 CSV 留在工位本地。

## 下载与安装

下载 `rp1-test-hmi_2.0.4+ubuntu24.04_amd64.deb` 和同名 `.sha256`，安装前正常停止现场测试并关闭自己的上位机：

```bash
sha256sum -c rp1-test-hmi_2.0.4+ubuntu24.04_amd64.deb.sha256
sudo apt install -o Dpkg::Options::=--force-confold ./rp1-test-hmi_2.0.4+ubuntu24.04_amd64.deb
```

应用名称为 `rp1-test-hmi`。现有用户配置保留，YAML 模块引用继续使用相对路径。
PLC V1.1 故障复位需配套实现 HR21～23 回执和故障来源寄存器的 PLC 程序；该 deb 不包含 PLC 程序。
