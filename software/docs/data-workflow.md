# 测试数据与审批

本手册描述当前 `reliability_v1`。账号权限审批、工位在线监控和测试数据审批相互独立。

## 本地记录与身份

HMI 在工位保存采集 CSV、报告、汇总和历史，测试完成不自动提交。集中归档后工位仍保留副本；原件大小与 SHA256 固定测量证据，测量事实不能通过应用接口编辑。

开始时选择正式用例或“其他”。“其他”必须填写测试名称、实际对象和工位。平台档案模式须有有效的样品、计划、周期、配置、分析段、用例版本、station 和 bench 关联；未选择平台档案的本地记录不要求平台 bench 身份，已选择但不完整的档案不能静默降级。

执行 UUID 是稳定身份；归档编号、正式执行编号和纠正前编号通过身份/别名关联。文件名和用例编号不能代替单次执行身份。`station_id` 与 `bench_id` 含义不同。

## 归档与送审

```text
工位结束并保存原件 → 用户核实 → 显式提交 → 专用接口分块上传
    → Worker 校验 SHA256 并解析 → 查看归档和曲线
    → 补齐正式归类及执行上下文 → 送审 PENDING
    → APPROVED / REJECTED
```

核实内容包括测试人、实际工位、人工结论和本次备注。SQLite outbox 冻结核实正文、原件大小/哈希与提交账号，入队后原件变化会拒绝上传，不能重新计算哈希接受新文件。

“其他”可先归档看曲线，保持 `UNCLASSIFIED`，再补正式用例和上下文。核实、归类修正追加版本；送审绑定具体版本。待归类、待审批和驳回记录不进入正式测试查询或统计。

PostgreSQL 保存身份、文件索引、核实/归类版本及审批记录；原始 CSV 和派生查询文件位于仓库之外的持久目录，由 API 与归档 Worker 共享。前端按权限查询，不直接访问存储目录或数据库。

## 权限与正式发布

| 操作 | 权限与约束 |
|---|---|
| 提交 | 已登录的人类执行员或管理员；提交人从服务端会话取得，重新校验执行上下文 |
| 核实、归类、送审 | 除角色外，按原提交人、管理员职责和具体接口权限检查 |
| 审核 | 执行员、管理员可审核，包括本人提交，必须填写意见 |
| 查看者 | 不能提交或审核；归档须已批准并完成正式归类，业务读取仍执行权限检查 |
| 建档 | 样品、项目、计划和台架创建受管理员权限限制；关联操作另查资源权限 |

网页登录与 HMI 平台登录使用人类会话，写请求要求 CSRF。应用权限和 PostgreSQL RLS 共同生效；不能把登录成功、账号角色或上传回执当作数据获批。

提交、不可改写的提交版本和审核记录分别保存；审核关联版本、审核人、结论、理由和时间。已批准版本不能覆盖或撤回；驳回后修正并显式重提，追加版本，保留旧证据和意见。

批准在同一数据库事务中检查当前版本、原件校验、冻结核实、归类、权限及上下文，发布执行、结果、运行时段、身份关联与审核记录。外键、区间重叠或版本错误会回滚整次发布、审计和重算任务。

批准后可进入正式执行查询及申报时长台账，但不自动取得合格 MTBF 暴露。机器测量、机器分析与人工结论分别保留；人工意见不能覆盖测得值。

## 幂等、并发与恢复

- 提交和审核携带稳定幂等键、版本号。同键同内容重放原结果，同键改内容或版本冲突返回 409。
- 锁与唯一约束避免重复发布，并发审核只能成功发布一次；不能通过更换执行身份绕过冲突。
- 网络中断保留本地文件和队列，按已确认分块续传。回执丢失沿用冻结正文/幂等键，不重复创建。
- 队列绑定原提交账号，切换账号不消费他人队列。待审只查状态，驳回停止自动重试，修正后显式重提。
- API/Worker 重启从持久状态恢复；校验、解析失败保留错误，不显示为批准或处理成功。
- 重新分析引用已发布用例的可计算规则，追加操作者、规则版本、原件哈希与结果；无可计算判据时为 `UNCONFIGURED`，不覆盖原分析、人工意见或正式结果。

## 网页历史 CSV 导入

入口为 `?view=csv-import`。浏览器识别并预览用户选定文件，确认上下文及核实后走同一中央归档、Worker 与审批流程。重复文件需要核对，不能重复制造事实。

不能从文件名或文件修改时间推断绝对采集时间。缺失绝对时钟时保留原始时间未知状态，人工补录与原始采集时间分别标记。仅有历史汇总或来源未核验摘要，不能自动升级为完整曲线或合格暴露。

## 在线监控与正式统计

HMI 登录后，网关默认每 10 秒发送工位、账号、并行会话、运行/暂停/故障及 PLC 状态，单次请求最长等待 5 秒。心跳独立于 CSV 上传队列。断网不积压旧心跳，恢复发送当前快照，序号阻止旧状态覆盖新状态。

网页区分在线、历史快照和状态待确认。离线不证明硬件停止，电柜供电不等于测试运行。在线投影可能关联原生实时执行身份，仍不能替代结束后的核实/审批，也不自动产生合格暴露；监控不提供远程 PLC/电机控制。

累计测试时长、运行时长、MTBF 暴露分开处理。有效暴露经过资格/scope 筛选与同一样品区间去重，待确认时间和故障分别显示。历史申报时长默认不能直接作为合格暴露，受控确认另有数据库约束，见 [数据库规则](../database/README.md)。
