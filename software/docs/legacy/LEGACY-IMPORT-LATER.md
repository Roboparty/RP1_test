# 旧 PostgreSQL 一次性导入（后续工作）

本轮不执行旧数据导入。

已确认边界：

- 权威旧 PostgreSQL 地址为 `10.43.16.186:5432`。
- 新系统不连接该地址。
- 后续由能够访问旧数据库的环境产生一次性 dump 文件。
- 不做增量同步。
- 不长期保留 dump 或 staging。
- 迁移业务数据，排除密码、会话、Token、presence 和临时队列。
- 不迁移旧 InfluxDB 和旧 NAS。
- 旧性能汇总不进入新老化分析。
- 旧测试时长进入统一累计测试总时长，但永久不进入新 MTBF 暴露。
- 现有样品的 MTBF 和长期性能周期在新平台启用后重新开始。

实施前必须先取得远程 schema 清单和字段样例，再编写一次性转换映射；不得假设远程库与本机当前开发库完全一致。
