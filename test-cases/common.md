# 公共执行规则

适用于全部整机用例；特殊的供电、恢复和中止条件以各用例为准。

## 试前固定

- **配置**：自由度、头部、硬件/BOM、固件与软件、控制参数、关节零位；样机用匿名编号。
- **工况**：地面/路线、负载质量与重心、夹具、主电池与备电版本、SOC、环境、保护阈值。
- **判据**：目标时长/里程/次数，温度和电压边界，允许性能变化，以及 F0～F3 检查内容。
- **基线**：按用例完成 F0/F1/F2；前后使用同一配置、负载、测法与测点。

F0～F3 的检查分级、测法和统一性能判据需由项目负责人批准；未确定时不判定用例通过。使用 [检查与执行记录](checklist.md) 保存方法、单位、试前基线、实际值、批准判据和证据。该表不替代分级与判据批准。

每次执行记录用例 ID、方法版本或 Git 提交，以及参数依据的文件版本、条款或项目试验依据。自定条件明确标注为项目依据，引用标准须记录准确编号、版本与条款。

## 基线与复测检查域

按下列检查域建立 F0～F3 的具体检查表，注明测法与判据。

| 检查域 | 重点 |
|---|---|
| 配置与外观 | 配置一致；紧固标记、脚底、线束、连接器与外壳 |
| 电池与安全 | 主/备电、BMS、充电与换电；急停、保护、复位与防坠 |
| 启动与运动 | 冷/热启动；站立、行走、转向、启停与姿态动作 |
| 关节与负载 | 零位、重复性、跟随误差、间隙；批准负载与夹具 |
| 头部与通信 | 运控/交互头；显示、视觉、音频；CAN FD、EtherCAT、USB、网络 |
| 热、噪声与退化 | 温升、风扇、降额；异响、磨损、润滑、胶粘、腐蚀与凝露 |

## 过程记录

每次执行关联用例 ID、执行编号、配置和起止时间；记录有效时长、里程/次数、计划暂停、非计划停机、人工干预和更换件。按用例保存温度、电压/电流、运动误差、通信与保护事件，以及同步日志和视频。

**老化与任务循环的有效运行时间不包含充电、换电、冷却和检查。** 环境暴露按各用例计时，端点内的功能检查计入暴露；吊挂承重或工况偏离时单独标记，不把中断和降载隐藏在累计结果中。

## 故障与通过

- 达到该用例的目标应力，安全项合格，试后复测达到事先冻结的性能判据，才能判为通过。
- 不可控动作、急停失效、电池异常或关键边界越限时，按用例立即安全停机并隔离异常样本。
- 保存故障阶段、信号、日志、处置与复测结果，进入故障闭环（FRACAS）；未闭环不得通过降载、降速或放宽保护继续累计。
- 改进后记录变更并复测受影响用例；资格结果与工程摸底结果分别记录。
