# 执行前参数清单

以下内容需由测试负责人在执行前确定，随方法版本、任务谱和批准记录保存。结果填入 [检查与执行记录](checklist.md)；尚未批准的项目保持待确认。

| 范围 | 需要确定 |
|---|---|
| 方法依据 | 各用例的方法版本或 Git 提交，参数的文件/标准版本与条款或项目依据；引用和批准记录。数值相似不能代替来源或符合性确认。 |
| 全部 | F0/F1/F2/F3 清单；统一性能判据；安全零容忍项及测法。90%指标也需定义“动态稳定能力”的量化方式。 |
| 002、016 | 按013进入安全姿态后换电，续接任务并单独记录暂停；确定换电流程与恢复条件。 |
| 样本与配置 | 确定002、008、014、021的自由度、头部配置与样本覆盖；确定010、011、012的样本量。各用例所列配置为参考工况，最终覆盖随执行版本固定。 |
| 008 | 电池45 ℃独立存储的时长；65±2 ℃工程摸底的时长及边界。不得把机身16 h自动套给电池。 |
| 010 | 共振定频10/30/90 min如何选；包装90 min的三轴分配；“显著共振迁移”的判据。 |

| 021 | 成功率、重试和人工干预阈值；确定搬运中的行走任务与002或016的关联。 |

## 016 姿态计数

50 km 累计至少 400 次姿态循环：300 次转向，加 100 次附加姿态动作。每 5 km 安排 10 次批准的附加动作，动作种类及计数定义在任务谱中固定。

## 工程摸底

45 ℃运行、65 ℃存储、加严冲击和动态跌倒作为单独工程摸底，明确批准边界后执行，结果与资格测试分别记录。
