# 检查与执行记录

本表用于保存试前基线、阶段检查、试后复测及改进复测。复制一份到本次运行资料目录填写，照片、日志和校准记录与该运行一同保存。

**F0～F3 的具体分级、测法及阈值尚待项目负责人批准。** 下表提供记录字段和测量说明，不为现有用例补造批准判据。等级、判据或必要测法未确定时，结论填写“待确认”，不据此给出通过结果。
