# SYS-REL-010 整机与包装振动

阶段：DVT。执行时同时遵循 [公共规则](../common.md)。

## 目的

发现运输/振动下的共振、紧固、连接和包装防护问题。

## 条件与设备

- 28运控、30交互，样本量待定；交付结构和包装，电池状态满足批准运输条件，F0～F2及紧固标记基线。
- 设备：振动台、验证承载/模态的夹具、加速度计、包装固定件与远程采集。

## 步骤

1. **非包装初始响应**：5～55 Hz、位移幅值0.15 mm、扫频≤1倍频程/min。
2. **共振定频耐久**：5～25 Hz（含25 Hz）为0.75 mm，>25～55 Hz为0.15 mm；评审选择10/30/90 min。
3. **非包装扫频耐久**：5～55 Hz、0.15 mm、≤1倍频程/min，三个正交轴各5循环；最终响应对比后F0～F2。
4. **包装随机振动**：默认运输等级2、90 min、总均方根0.604 g；三轴时间分配待定，记录包装状态并复测。

| 频率（Hz） | 功率谱密度（g²/Hz） |
|---|---|
| 2 | 0.0005 |
| 4 | 0.012 |
| 18 | 0.012 |
| 40 | 0.001 |
| 200 | 0.0005 |

## 记录

台面/样本响应、共振迁移、放大倍数；紧固与连接、电池固定、零位/间隙；包装位移、缓冲压溃及附件碰撞。

## 通过与中止

- 无裂纹、永久变形、松动、脱落、电池位移或危险共振；响应变化可解释，性能合格，包装仍具防护能力。
- 夹具松动、控制失真、样本位移或共振快速增长立即停台；额外扎带/泡棉只能作为改进后完整复测的方案。
