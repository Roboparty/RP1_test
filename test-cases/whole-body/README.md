# 整机测试用例

本目录保存18项RP1整机方法草案，完整分类与目标参数见 [用例索引](../README.md)。测试覆盖持续运行、带载、温湿环境、存储恢复、机械应力、保护恢复和典型任务。

## 文件约定

文件名采用 `SYS-REL-编号-英文名称.md`。每项包含：目的、条件与设备、步骤、记录、通过与中止。

| 方向 | 用例编号 |
|---|---|
| 持续运行与带载 | 001、002、003、016 |
| 温湿环境与存储 | 004、005、006、007、008、009 |
| 振动、冲击与倾倒 | 010、011、017 |
| 保护与恢复 | 012、013、014 |
| 动态与操作任务 | 020、021 |

## 执行前阅读

- [公共规则](../common.md)：配置、基线、有效计数与故障闭环。
- [执行前参数清单](../open-items.md)：检查分级、性能阈值与配置覆盖。
- [用例模板](../_template.md)：新增或修订方法。

方法仍待实测，不包含完整执行数据。参数采用 RP1 参考工况，应用于其他机器人时需核对负载、供电、环境与保护边界。

## 自动化与记录

可自动化动作通过 [test-runner](../../software/test-runner/README.md) 关联用例ID；人工与设备操作仍保留在用例步骤中。每次运行保存配置、有效目标完成量、中断、异常和试后复测，按 [分析指导](../../data-analysis/docs/README.md) 比较性能变化。
