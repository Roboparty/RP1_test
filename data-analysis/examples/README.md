# 示例数据与预期结果

提供能解释分析过程、核对软件输出的记录。**当前尚无示例文件；以下目录与文件名为计划。** 合成数据与匿名真实记录分别存放，并在元数据和说明中注明来源。

## 首版：合成运行

```text
synthetic-run/              # 待生成
├── README.md               # 生成假设、适用问题与预期指标
├── baseline/               # 基线运行
│   ├── telemetry.csv       # 双关节时序、单位与缺失片段
│   ├── events.jsonl        # 暂停、保护和中断
│   └── metadata.json       # synthetic标识、工况与确认区间
├── retest/                 # 同工况复测，包含同样三类文件
└── expected/               # 单次摘要、基线对比与事件解释
```

输入为同工况的基线/复测两组短时合成数据及 [分析配置](../config/README.md)；输出为 [三个分析脚本](../scripts/README.md) 预期生成的摘要、对比和时间线。生成说明需列出采样频率、信号公式、单位、active intervals、暂停与缺失安排，避免把人为设置的异常解释为真实故障机理。

样例用于演示001/003的温升与有效时长、012的保护事件和基线比较方法。短时记录不能表示完成3 h站立、50 km行走或任何完整用例；示例阈值只验证工具行为，不代表产品判据。

## 后续：匿名真实片段

计划另建 `anonymized-run/`，选择“异常出现—安全停机—排查—复测”记录。保留相对时间、配置、工况、关键信号和处置；使用匿名运行编号，说明截取区间与删减字段。根因未确认时保持待排查，不补写解释。

真实片段需关联 [对应测试用例](../../test-cases/README.md)，注明数据是完整运行还是片段。若只有片段，只解释可见事件，不推算整次任务时长或可靠性指标。由 [上位机](../../software/host/README.md) 导出的原始字段与匿名后的映射关系也应说明。

**完成条件：** 每组样例都有来源、假设、输入、配置和预期输出；分析可离线复现，预期值能独立核对，合成与真实身份清晰且不混用。
