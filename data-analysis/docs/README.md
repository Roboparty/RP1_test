## 共同约定

先确认 active intervals，再计算有效任务时长；换电、检查、冷却和异常暂停分别保留。跟随误差按同动作、负载和阶段的 active 样本比较，报告峰值与均方根。温度统计保留全程，有环境温度时才计算温升。

缺失值保持未知，断采期间不外推正常运行。里程、制动距离和抓取成功率需要对应任务记录；能耗需要电压、电流及时间，不能以关节扭矩代替。异常信号、故障确认、根因和复测结论分开描述；单次运行不推 MTBF，脚本不自动判 PASS。

**完成条件：** 每篇指导均说明必要输入、计算范围、输出和不足条件，并能带读者完成 [合成示例](../examples/README.md)；计划文件发布后再加入直接链接和运行命令。
