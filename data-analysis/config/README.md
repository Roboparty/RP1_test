# 分析配置与字段映射

将不同机器人记录转换为明确单位和统计范围的分析输入。**当前只有配置说明；以下JSON模板尚未生成。** 配置随运行保存，使用者按对应 [测试用例](../../test-cases/README.md) 填写实际值。

| 计划模板 | 输入与作用 |
|---|---|
| `field-map.example.json` | 原始列名、单位、缺失编码 → 规范字段与转换规则 |
| `run.example.json` | 用例、机器人/软件、负载、环境、目标 → 工况和确认的任务区间 |
| `limits.example.json` | 批准的观察边界、来源和版本 → 指标标记；示例值单独注明 |

## 兼容的遥测字段

| `rp1_test`字段 | 含义 / 单位 |
|---|---|
| `time_s` | 相对采集时间，s |
| `joint_name`、`motor_index` | 关节与电机标识 |
| `cmd_pos_rad`、`pos_rad` | 指令/反馈位置，rad |
| `spd_rad_s` | 反馈角速度，rad/s |
| `torque_nm` | 反馈扭矩，N·m |
| `temp_c` | 温度，℃ |
| `error_id` | 设备错误码，需附设备解释或映射 |

本地分析保留rad/rad/s；现有平台接入使用deg/deg/s，转换责任在采集接入端。字段映射需注明来源单位和目标单位，避免重复转换，关系见 [上位机](../../software/host/README.md) 与 [Service](../../software/service/README.md)。

## 区间与缺失规则

active intervals必须来自已确认的任务状态，注明起止、时间基准及确认依据；主动运行、换电、冷却、检查和非计划暂停分类记录，区间互不重叠。有效任务时长使用这些区间；误差只分析同工况active样本，温度保留全程。

空值及原始CSV的NaN识别为缺失，不能填0；缺少温度、位置或任务记录时，输出相应数据不足。错误码缺失不能解释为“无故障”。不同配置、负载和环境先核对再比较。

## 模板完成条件

每个字段给出类型、单位、必填条件和来源；区间能关联遥测与事件的同一时间基准；演示值与批准阈值清楚区分。模板应能支撑 [合成样例](../examples/README.md) 与 [分析脚本](../scripts/README.md)，不包含真实连接信息。配置不自动授予PASS，单次运行也不据此推导MTBF。
